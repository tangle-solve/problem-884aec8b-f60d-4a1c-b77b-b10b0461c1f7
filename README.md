### ALGO-000008: Exponential Time Hypothesis (ETH)
- **Subfield:** fine-grained complexity
- **Open:** Is 3-SAT not solvable in 2^{o(n)} time?
- **Status:** Open since 1999; implied by SETH. Contrasts with subexponential algorithms known for restricted formulas (Schöning 1999).
- **Type:** theory
- **Why:** Underlies the (no subexponential algorithms for NP-hard problems) view; base of many reductions in parameterized complexity.
- **Key works:** R. Impagliazzo, R. Paturi, "On the complexity of k-SAT", JCSS 2001
